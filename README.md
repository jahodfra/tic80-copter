# Copter Quest

A TIC-80 (0.90) game: fly a helicopter over a detailed Earth and find real cities.

The copter flies on a sphere: the view always faces the flight direction, the
world rotates underneath when turning, and straight flight follows a great
circle, so you can fly right over the poles.

Controls: up fly forward, down brake/reverse, left/right turn, S hold for
turbo, Z land on the city below, X world map, A compass hint (costs 150 points
of the round). The needle top right points north.

## Layout

- `cart/src/*.lua` – game code, joined into one cart (`00_header` is the metadata,
  `20_cities.lua` is generated).
- `cart/sprites.gif` – palette, terrain textures, coast masks, mountains, towns
  (generated by `tools/make_sprites.py`, editable in TIC-80 afterwards).
- `tools/build_world.py` – terrain grid: NASA land cover (`lcc_global_8192.tif`) +
  NOAA ETOPO5 elevation/bathymetry → 2048-cell equal-area grid (~20 km/cell) with
  13 land classes, 4 relief levels and 3 water depths, RLE packed (~170 KB) into
  the map memory of cart banks 1..6.
- `tools/build_cities.py` – 708 cities from Natural Earth populated places.
- `tools/build_cart.py` – cart builder (adds `--bank-data`).
- `tools/tic80remote/` – headless runner on the real TIC-80 core for testing.

## Build

    make            # downloads ETOPO5 on first run, builds build/copter.tic
    make run        # opens it in ./tic80
    make sprites    # regenerate cart/sprites.gif (overwrites edits!)
    make cities     # regenerate cart/src/20_cities.lua
